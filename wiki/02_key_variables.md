# 02. 關鍵變因控制

> **資料來源**：[Source 1] 萃取率與金杯區、[Source 3] 水質硬度與礦物質

## 1. 粉水比（Brew Ratio）
粉水比是「咖啡粉重：總注水量」，主要決定咖啡的**濃度（TDS）**與口感厚薄：
- **常見黃金區間**：`1:15` ～ `1:17`（例如 15g 粉配 225ml ～ 255ml 水）。
- **比例越濃（如 1:13）**：口感厚實、濃郁，但容易萃取不足。
- **比例越淡（如 1:18）**：口感輕盈、茶感，但若水量過多容易拉高萃取率導致雜味。

## 2. 研磨度（Grind Size）
研磨度改變咖啡粉的「總表面積」與「水流阻力」：
- **磨越細**：表面積大、水流慢、接觸時間長 → **萃取率提高**（風味濃郁，過細易苦澀或堵塞）。
- **磨越粗**：表面積小、水流快、接觸時間短 → **萃取率降低**（風味清爽，過粗易尖酸水感）。

## 3. 水溫（Water Temperature）
水溫決定熱能與分子的溶解速度：
- **高水溫（90°C ～ 94°C）**：適合淺焙豆（豆質較硬、密度高），幫助釋放果酸與花香。
- **中低水溫（85°C ～ 89°C）**：適合中深焙豆（結構較疏鬆、易萃取），避免把焦苦味過度拉出。

## 4. 水質硬度與礦物質（常被忽略的關鍵）
咖啡有超過 98% 是水，水中的礦物質直接參與化學萃取：
- **鈣（Ca²⁺）與鎂（Mg²⁺）離子**：負責抓取咖啡中的香氣與甜感分子；**過硬的水**會讓風味變得鈍重、悶濁。
- **鹼度（碳酸氫鹽）**：會中和咖啡中的有機酸。鹼度過高會讓淺焙豆失去明亮果酸，喝起來平淡無趣。
- **實務原則**：「**先調水質、再調研磨**」。使用過濾水或總硬度適中（約 50–100 ppm）的軟水，比一直改沖煮手法更有效。
